# tiltport

Tilt and reshape port text streams with deterministic transforms.

**Site:** https://theworker02.github.io/tiltport/

## Install / run

```bash
git clone https://github.com/theworker02/tiltport.git
cd tiltport
node src/cli.js
node --test
```
